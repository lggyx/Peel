# Screenshot Checklist for MeDo

Upload screenshots that show what Peel already does. These help MeDo match the product's actual interaction model instead of inventing a generic landing page.

## Recommended Screenshots

1. Video library / empty state.
2. Add video URL sheet.
3. Successful video analysis result.
4. Player page with AI assistant panel.
5. Storyline tab.
6. AI chat success state.
7. Any error state worth explaining.

## Naming Convention

Use simple English filenames before uploading:

```text
01-library-empty.png
02-add-video-url.png
03-analysis-results.png
04-player-ai-panel.png
05-storyline-tab.png
06-ai-chat-success.png
```

## What Not to Upload

- `.env` files.
- API keys.
- screenshots showing private tokens.
- Android Studio setup screenshots unless they explain development process.
- `node_modules`, `dist`, or Android build output.

## Visual Guidance for MeDo

Tell MeDo to preserve these product signals:

- dark cinematic interface,
- video-first layout,
- timeline/storyline cards,
- AI chat panel,
- mood-based colors,
- mobile-first demo flow.
